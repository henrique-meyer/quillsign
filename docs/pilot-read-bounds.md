# Restricted pilot browser and document access

The optional read scope adds the immutable pilot run deadline after ordinary party authentication. It does not authenticate a browser, change the saved document retention policy, impersonate a signer or grant provider/storage authority. A public identifier or operator capability never replaces the ordinary sender, signer or completion-reader proof.

Known enrollment is read independently of current pilot configuration. Disabling a run, rotating its identifier or capability, missing/corrupt private evidence and enabling public email reject known cohorts instead of falling through to ordinary authority. Keep this read composition installed after disabling the pilot; unregistering it would deliberately restore ordinary-host behavior and is not the shutdown procedure.

New sender cookies, signer sessions, completion links/readers and final download grants end no later than the fixed run. Existing token records and signed session identities remain unchanged because they are evidence bindings. Every action revalidates persisted cohort authority, including before commit, after acknowledged commit/disposal and after slow file reads. Lost acknowledgements expose no new browser proof; committed work is not discarded or repeated. Denial means restricted test access ended, not that seven-day retention was shortened or data was already purged.

The source extension is lazy and unregistered from startup in this slice. Default hosts keep ordinary behavior and do not resolve a database or key ring merely by resolving the optional scope/filter. Final operator/worker composition, cleanup and deployment are tracked separately.

Validation includes real SQL with configuration changes before/after commit, normal captured link redemption without seeded verification, actual signer evidence and sequential completion with local fake timestamp accounting, exact bytes, proof limits near cutoff, expired/disabled reads after IO and a real browser upload/review/disable/expiry flow. These are local synthetic tests, not hosted mail-delivery evidence.
