# Internal values-only XLSX conversion

QUILS-108 adds the default-disabled content component. QUILS-124 adds [guarded sender intake](document-conversion.md#guarded-static-office-intake), requiring `Documents__EnableOfficeUploads=true`, `OfficeConversion__XlsxEnabled=true` and a usable isolated HTTP converter. The existing hosted sandbox remains DOCX-only; no hosted XLSX activation is included.

The gate accepts a conservative SpreadsheetML subset: visible values-only sheets, literal inline/shared strings, finite static styles, ordinary merged headers, and bounded cells. It rejects every formula, formula-bearing name, external or refresh source, hidden sheet/row/column, macro, OLE/embedded package, chart/drawing, comment, printer binary, protection, extension or unknown part/relationship/namespace. An empty inert workbook-protection element is permitted. Unsupported files must be exported to PDF. This is not general Excel support and does not calculate formulas from cached results.

Bounds include at most ten sheets (also subject to configured PDF limits), A1:L40 per sheet, 480 cells per sheet, 4,800 overall, 100 characters per literal cell, 50,000 displayed text characters including repeated shared strings, finite numbers, 32 fonts/fills/borders, 100 cell styles, bounded font/alignment/row/column/merged-cell work, and common ZIP expansion/XML limits. Coordinates, actual cells and references are checked independently of declared dimensions. DTDs, processing instructions and aliases fail before conversion. No external document is passed through on the strength of its suffix.

The exact original workbook bytes and SHA-256 remain owned and independently readable. A separate owned conversion workbook changes only worksheet print settings to A4 landscape, quarter-inch margins, one page per visible sheet, with no header/footer area. Cell data, styles and other approved parts are preserved. The converter sends only this separately hashed copy, using the fixed enum-selected `document.xlsx` name and SpreadsheetML media type. It verifies that precise derived input, normalizes the returned PDF and checks every page's count, rotation, unit and landscape A4 geometry. The returned original hash is the uploaded workbook's hash. No converter filename or command comes from user input.

Explicit review of the exact normalized PDF is mandatory: print scaling and font substitution can differ from the author's spreadsheet application. Large or rich workbooks are rejected rather than partially rendered, stripped or converted to silently substituted literal values. QUILS-124 stores the exact original and normalized PDF separately under the existing fixed retention, with independent derived print-copy provenance.

Local evidence covers minimal and normally generated styled values workbooks, merged headers, Unicode, boolean/numeric values and literal formula-looking text. Four real pinned-service output pages were rendered and inspected. Adversarial tests cover formulas, hidden/resource/embedded structures, malformed containers, repeated text and sparse/large grid work; HTTP error, disabled flag, cancellation, page/geometry mismatch and disallowed sandbox transport fail closed. The converter stays on its isolated network with no default route. This evidence does not authorize provider calls or claim hosted availability.
