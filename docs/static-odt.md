# Internal static ODT conversion

QUILS-109 adds a default-disabled ODF text component. QUILS-124 adds [guarded sender intake](document-conversion.md#guarded-static-office-intake), requiring `Documents__EnableOfficeUploads=true`, `OfficeConversion__OdtEnabled=true` and a usable isolated HTTP converter. Exact original/PDF publication and explicit preview confirmation use the existing retention workflow. No hosted activation or sandbox input is added.

The ODF gate checks the physical first ZIP member: `mimetype` must contain exactly the ODT media type, stored without compression, extra fields or a data descriptor. Shared raw ZIP/header/CRC/canonical-path/decompression checks remain unchanged for OPC formats. A separate ODF manifest must enumerate every supported content part exactly once with matching media types; aliases, unexpected paths, encryption and signatures fail before LibreOffice.

This profile accepts literal paragraphs/headings/spans/spacing, finite static styles, simple nonmerged tables and verified internal PNG/JPEG images anchored inline. It requires one portrait A4 page layout and one empty master page. Fonts, margins, tables, characters, explicit spaces/page breaks, style inheritance, references, image geometry/pixels and XML work are bounded. It rejects scripts/events/forms, fields, sections, hyperlinks/external resources, embedded objects, binary data, headers/footers, floating images, row/column repeats or merges, style cycles, unknown namespaces/attributes/parts and opaque settings/printer content. A typical richer LibreOffice document may be outside this initial profile; export it to PDF. Unsupported content is rejected, never silently removed.

The exact accepted original stays owned with its SHA-256. A fixed enum selects `document.odt` and the ODT media type for the isolated HTTP converter; neither path nor command comes from the document. The returned PDF is normalized and independently bounded by configured byte/page limits, with portrait A4 geometry checked on every page. Flowing text does not imply an exact source page count; this gate makes no such claim. The guarded sender integration preserves original/PDF hashes and requires explicit review of those exact normalized bytes.

Local validation converts a two-page synthetic text/table document and a second document containing a content-verified four-color PNG through the real pinned isolated service. All four pages were rendered and inspected; Unicode, literal URL/markup/formula-looking text, tables and image placement remain visible. Adversarial tests cover manifest/member discrepancies, compressed or misplaced mimetype, active content, external resources, malformed XML/ZIP, oversized/repeated work, style cycles, provider errors, disabled configuration, cancellation, geometry mismatch and refused sandbox transport. No new dependency or live provider use is involved. The service remains on its existing network without a default route; public email and hosted formats remain unchanged.
